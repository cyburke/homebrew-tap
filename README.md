# cyburke/homebrew-tap

Homebrew tap for my macOS tools.

## Hey Codex

Say "Hey Codex" and ChatGPT Voice opens. [Source and docs.](https://github.com/cyburke/hey-codex)

```bash
brew install --cask --no-quarantine cyburke/tap/hey-codex
```

The `--no-quarantine` flag is required because the app is not notarized. See the [main repo](https://github.com/cyburke/hey-codex#why-macos-warns-you) for what that means.
